# Paint Puzzle: Painty Path

A swipe paint puzzle: roll the brush through mazes and fill every tile.

- Google Play: https://play.google.com/store/apps/details?id=com.jeetech.g001
- Privacy policy: https://jeet-s.github.io/jeetech-g001/privacy.html
- Current version: 1.0.7

`game/` is the Expo (React Native) source as shipped; `store/` holds the listing and graphics.
